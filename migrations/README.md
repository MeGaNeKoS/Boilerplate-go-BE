# Database Migrations (`migrations`)

This folder stores the SQL migration files executed when the service starts.
Each migration is split into matching `*.up.sql` and `*.down.sql` files. New
migrations are generated by diffing the canonical schema in the `schema`
directory against the current database.

The entry points call `RunMigrations` during startup using the path configured
in `config.yaml` (defaults to `file://migrations`). Pending migrations are
applied automatically to keep the schema in sync with the code base.
